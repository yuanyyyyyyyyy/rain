## 三、管理台六个页面分别干什么

### 01 概览 —— 看数据
- 今日/累计访问量（PV）、访客数（UV）、14 天趋势图、热门页面 Top5、来源 Top5
- **口径**：PV = 页面访问次数（同一访客同一页面 1 分钟内去重，不是原始刷新数）；访客数 = 全历史 IP 去重（北京时间口径）
- 左上角标注数据来源：「Worker（公网）」= 真实访客数据；「本地」= 本地联调数据（通常为 0）。侧栏底部「数据源」按钮显示当前公网/本地状态
- 数据源在 **06 / 设置 → 数据源** 配置（带测试连接）；简历下载 / 来源 Top5 仅公网数据源可见

### 02 照片管理 —— 管理摄影页
- **上传**：拖图片进上传区 / Ctrl+V 粘贴截图 / 点击选择 → 逐张确认分组与日期（**拍摄日期自动从 EXIF 识别**，识别不到用文件时间兜底，上传后仍可改）→ 点上传（并发 2，失败可单张重试）
- **调整**：组内/跨组拖拽排序、点「编辑」改日期/分组/**图注**（图注会显示在摄影页）、「设头图」（全局只有一张）
- **删除**：点「删除」→ 二次确认（文件+记录一起删）
- 页面出现「● 有未发布变更」横幅 = 改动还没上公网，去 04 发布

### 03 项目内容 —— 改项目详情页文案
- 顶部切换项目（yunshu / intelnexus / **forge / rain / shimmer**）
- 基本信息：标题、摘要、头注释（证据说明，发布时保留在文件里）
- META：详情页右侧「FILE / META」侧栏，增删行
- 分节编辑：「新增节」下拉已中文化（界面截图/核心实现/数据指标/踩坑复盘/正文段落，各有说明）；架构图节只读；编号自动顺延（01 概述由页面自动渲染，不用新增）；正文段落的换行会保留
- **预览 ↗** 按钮：打开公网项目页（显示的是已发布内容）
- 新建项目：点「+ 新建」在弹窗里填 slug/名称/简介（发布后卡片与详情页自动上公网，无需改代码）
- 改完点「保存」（保存 ≠ 公网生效；页头有未发布提示）

### 04 发布 —— 改完内容点这里
- 点「一键发布」→ 确认 → 约 6 秒完成
- 它自动做了：写回网站数据文件（含新照片/截图二进制）→ 提交（git commit）→ 推送 GitHub → 触发部署
- **「公网部署进度」面板**会真实跟踪 GitHub Actions：排队 → 构建中 → 已部署（每 10 秒自动刷新）
- **当前状态**里的「未发布变更」会列出具体哪些文件还没发布

### 05 收件箱 —— 看访客留言
- 公网访客在网站底部表单发的留言出现在这里（**前置条件**：06 设置里配好数据源，否则空态会提示你先配置）
- 未读有蓝色标记，点一下即已读；侧栏角标显示未读数
- **邮件通知**：配置 Brevo（见 cloudflare/README.md）后，新留言会自动转发一封通知邮件到你邮箱，回复邮件直接送达访客

### 06 设置 —— 账号与数据源
- **数据源**：让概览/收件箱读公网真实数据。填 Worker 地址 + ADMIN_TOKEN（留档在 `cloudflare/.admin-token.local`），有「测试连接」按钮，保存即生效不用刷新
- **修改密码**：改完下次登录用新密码

## 七、常见问题（FAQ）

**Q：打开管理台是登录页，账号是什么？**
用户名 `admin`，密码在 `admin/server/.admin-password.local`（本地文件，不在代码仓库里）。

**Q：双击 bat 后浏览器打开的是空白/登录页打不开？**
等 10 秒刷新。后端启动要十几秒；也可以看 bat 窗口里 `http://localhost:5175` 还是 `5176`。

**Q：点发布显示成功，公网怎么没变？**
看 04 页面「公网部署进度」面板：显示「已部署 ✓」后再强刷（Ctrl+F5）。如果推送失败，开代理后手动执行 `python tools/sync-via-api.py` 即可补推（断点续传，重跑安全）。

**Q：侧栏「04 / 发布」旁边有个黄点？**
那是"未发布变更"提醒：照片/内容已经保存进数据库，但还没点发布，公网看到的还是旧内容。点进 04 发布即可。

**Q：概览页数字是 0？**
访客数据来自公网：① 有人访问才有；② 确认 06 设置里数据源已配置且「测试连接」通过——workers.dev 国内直连间歇受限，开代理时最稳定，连不上时自动切本地（本地数据通常为 0）。

**Q：访客说表单发不出去？**
国内直连网络下前端会自动降级成"请邮件联系"（无害，不会乱弹邮件客户端）。彻底解决=买个域名绑到 Worker（一年几十元），想做了找 agent。

**Q：管理台页面数据不动了/显示 0 条很奇怪？**
先刷新页面（F5）；还不行就关掉 bat 的窗口重双击。曾出现过旧实例残留导致的假死，重启即好。

**Q：照片上传后摄影页没看到？**
看页面顶部有没有「● 有未发布变更」横幅——上传只入库，点「04 发布」后才写进网站并部署公网。

**Q：拍摄日期不想用自动识别的？**
上传前在待上传队列里直接改（改过的以你填的为准），或上传后点「编辑」改。

## 八、技术底细（想了解再看）

- 网站本体：Vue 3 纯静态，部署在 GitHub Pages（免费），Actions 自动部署

- 公网数据接收：Cloudflare Worker + D1（免费层），代码在 `cloudflare/`，部署手册在 `cloudflare/README.md`（含留言邮件通知配置）
- 全部代码：https://github.com/yuanyyyyyyyyy/rain （完整开发历史）
