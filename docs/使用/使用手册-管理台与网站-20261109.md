## 三、管理台五个页面分别干什么

### 01 概览 —— 看数据
- 今日/累计访问量（PV）、访客数（UV）、14 天趋势图、哪些页面最受欢迎
- 左上角标注数据来源：「Worker（公网）」= 正在读公网访客数据；「本地」= 读本地（开代理后 Worker 更稳定，8 秒连不上会自动切回本地，不用管）

### 02 照片管理 —— 管理摄影页
- **上传**：选文件 → 选分组（街道/光线/日常）→ 选拍摄日期（可不填）→ 上传（自动压缩成长边 1600）
- **调整**：组内拖拽排序、点「编辑」改日期/分组、「设头图」（摄影页大图，全局只有一张）
- **删除**：点「删除」→ 二次确认（文件+记录一起删）

### 03 项目内容 —— 改项目详情页文案
- 顶部切换项目（yunshu / intelnexus）
- 基本信息：标题、摘要、头注释（证据说明，发布时保留在文件里）
- META：详情页右侧「FILE / META」侧栏，增删行
- 分节编辑：架构图节只读（是代码画的 SVG）；其余每节可加条目/删条目/上下移动，编号自动顺延
- 改完点「保存」

### 04 发布 —— 改完内容点这里
- 点「一键发布」→ 确认 → 约 6 秒完成
- 它自动做了：写回网站数据文件 → 提交（git commit）→ 推送 GitHub → 触发部署
- **约 1 分钟后公网站点更新**（发布历史里能看到每次记录和构建日志）

### 05 收件箱 —— 看访客留言
- 公网访客在网站底部表单发的留言出现在这里
- 未读有蓝色标记，点一下即已读

## 七、常见问题（FAQ）

**Q：打开管理台是登录页，账号是什么？**
admin / admin123。仅限本地使用。

**Q：双击 bat 后浏览器打开的是空白/登录页打不开？**
等 10 秒刷新。后端启动要十几秒；也可以看 bat 窗口里 `http://localhost:5175` 还是 `5176`。

**Q：点发布显示成功，公网怎么没变？**
等 1 分钟再强刷（Ctrl+F5）。发布历史（04 页面）里看最近一条的构建日志确认；如果出现「推送失败」，开代理后手动执行 `python tools/sync-via-api.py` 即可补推。

**Q：概览页数字是 0？**
访客数据来自公网：① 有人访问才有；② Cloudflare Worker 的地址（workers.dev）在国内直连间歇受限——开代理时最稳定，连不上时管理台自动切本地数据（左上角会显示当前来源）。

**Q：访客说表单发不出去？**
国内直连网络下前端会自动降级成"请邮件联系"（无害）。彻底解决=买个域名绑到 Worker（一年几十元），想做了找 agent。

**Q：管理台页面数据不动了/显示 0 条很奇怪？**
先刷新页面（F5）；还不行就关掉 bat 的窗口重双击。曾出现过旧实例残留导致的假死，重启即好。

**Q：照片上传后摄影页没看到？**
点「04 发布」了吗？上传只入库，发布后才写进网站并部署公网。
