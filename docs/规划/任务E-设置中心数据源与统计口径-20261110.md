## 一、审计结论

- **设置页形同虚设**：SettingsPage.vue（129 行）只有改密码表单；「数据源」配置反而在侧栏 `LayoutPage.vue:50-63`，用两次浏览器原生 `prompt()`（原文：「Worker 地址（留空清除，回退本地后端）：」「ADMIN_TOKEN：」），零解释、无校验、保存后要手动刷新（alert「已保存。刷新页面生效。」）。
- **数据源机制（给用户的解释，直接可做成 UI 文案）**：
  - 公网站点没有后端，真实访客的埋点/留言/简历计数全在 Cloudflare Worker + D1 里；本地 Spring 只能收本地联调数据。
  - 「数据源」= 告诉管理台去哪读统计和留言：填 Worker 地址读**真实公网数据**；留空/连不上（8 秒超时，api.js:97-114）自动回退**本地后端**（数据通常为 0）。
  - 填什么：Worker 地址 = `https://rain-collector.yuanyyyyyyyyy.workers.dev`；ADMIN_TOKEN = 部署 Worker 时 `wrangler secret put ADMIN_TOKEN` 的那串（本机留档 `cloudflare/.admin-token.local`）。**它和管理台登录密码是两套独立凭证**。
  - 影响范围：仅 01 概览、05 收件箱；02/03/04 页永远走本地 Spring。
- **PV 口径**：一条 visit = 同 IP 哈希 + 同路径 + 同一分钟去重（worker.js:41-44、63-71；Spring StatsController.java:50 同口径）——不是原始刷新数。UV = 全历史 IP 去重数（非今日 UV）。UI 上无任何口径说明。`ua` 字段存了但没有任何查询用到（设备统计预留未做）。
- 缺口：Worker 返回的 `topReferrers`（worker.js:119-122）DashboardPage 没渲染；本地 Spring 源缺 `resumeDownloads`/`topReferrers` 能力不对齐；无按天 UV/导出。

## 二、任务清单

### P1-1 「数据源」搬进设置页，废弃 prompt() 弹窗
- SettingsPage 新增「数据源」卡片：两个带标签输入框 + 内联说明文案（上面第一节的解释直接改写为 UI 文案，含"地址去哪找 / token 是什么 / 留空回退意味着只能看到本地联调数据"）。
- 保存即生效（重拉数据，免手动刷新）；废弃 `LayoutPage.vue:50-63` 整段 prompt 逻辑。
- 加「测试连接」按钮：调一次 `/stats/summary`，三种结果——401=token 错 / 超时=地址错或需代理 / 成功=显示 `累计 PV N` 预览。
- 格式校验：URL 必须以 `https://` 开头（现在填 `htps:/...` 也照样存）。

### P1-2 数据源状态可视化
- 侧栏「数据源」按钮旁显示当前生效状态徽标（公网 / 本地 / 回退），替代现在只有页面左上角一行小字。
- **未读徽标改读当前数据源**：`LayoutPage.vue:38-45` 的 `/api/messages/unread` 现在恒读本地（D1 有新留言徽标也恒 0）——按 api.js 现有 workerSend 模式走当前数据源，Worker 侧若无 unread 端点则前端用列表数计算（核实 worker.js 是否已有 `/messages?unread=` 能力，没有就在 Worker 加）。

### P1-3 PV/UV 口径说明 + 补齐统计出口
- 概览统计卡加 tooltip/脚注：「PV：页面访问次数（同一访客同一页面 1 分钟内去重）；UV：全部历史去重访客数（按 IP 哈希）」。
- 渲染 `topReferrers`（来源 Top5 面板，Worker 已有数据）；本地源缺 `resumeDownloads`/`topReferrers` 时显示「仅公网数据源可用」而非悄悄消失。
- 可选：Spring StatsController 补齐 topReferrers（visit_log 已有 referrer 列）使两源能力对齐。

### P2 设置分组扩展
- 账号安全（改密 + 可选"退出全部会话"——需后端 JWT 黑名单或改 signing key，成本高可后置）；
- 通知占位卡（留言邮件提醒开关——依赖任务 D 的邮件能力，先放 UI 占位或直接不做）；
- 数据管理（统计 CSV 导出——前端从 summary 拼即可）。
- 本地 Spring 侧可选清理：`ua` 列要么用起来（设备统计）要么从写入中去掉，别留无用字段。
