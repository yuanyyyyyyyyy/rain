## 二、新增 / 优化清单（按推荐顺序，本批全部开发）

### F1 · Worker 留言管理对齐本地（软删/回收站/恢复/彻底删）⭐ 一致性硬伤
**问题**：收件箱配 Worker 数据源（= 真实公网留言所在）时不能删除/回收站——UI 明确提示"切本地才能管理"，而本地几乎永远没数据，软删回收站功能对真实数据形同虚设。
**方案**：
- D1 migration 0002：`messages` 加 `deleted`/`deleted_at` 列 + 索引；schema.sql 同步（新装一致）
- Worker 对齐 Spring 契约：`GET /messages` 只回未删、`GET /messages/trash`、`DELETE /messages/:id`（软删）、`POST /messages/:id/restore`、`DELETE /messages/:id/purge`（仅回收站内）、`DELETE /messages/trash`
- UI 解锁：InboxPage 移除 isWorker 限制；Worker 未升级（404）时给出"请部署最新 worker.js + 0002 migration"提示而非裸报错
- 顺手：邮件通知每日帽改「只统计未读」（五路审计建议），被刷后读过即恢复通知能力
- CI：verify-collector 加 token 化软删 round-trip 断言（发布→软删→回收站→恢复→彻底删→消失）
- 验证：wrangler dev 本地 D1 端到端；**remote migration 与 wrangler deploy 留给站长**（上线步骤输出在交付说明）

### F2 · 内容页截图直传 ⭐ 打通内容闭环
**问题**：shots 节只能引用 `public/screenshots/<slug>/` 里已存在的文件——外部交付截图要手工拷文件（昨晚 Shimmer/IntelNexus 均为命令行拷贝），管理台"内容自闭环"断在最后一步。
**方案**：后端 `POST /api/content/screenshots/{slug}`（multipart；slug 复用既有正则、扩展名白名单 png/jpg/jpeg/webp、≤2MB、文件名 sanitize、同名拒绝）；前端 shots 编辑区加"上传截图"入口，成功后刷新 datalist 并自动追加图注行（caption 留空待填）。发布管线已 git add public/screenshots，零改动。

### F3 · 收件箱搜索
前端内存过滤（列表 ≤100 条）：按姓名/邮箱/正文包含匹配，与 Tab 筛选叠加；不引入后端 q 参数（等真实需求）。

### F4 · 概览页增强：时间范围 + 最近留言
- 趋势图 7/14/30 天切换：Worker 与 Spring `/stats/summary` 同步加 `?days=N`（响应新增 `daily`+`range`，**保留 `daily14`** 兼容旧 UI）
- 「最近留言」预览卡（数据源感知 + 跳收件箱）+ 今日留言数卡片

### F5 · 照片批量操作
批量选择模式：批量隐藏/恢复、批量设拍摄日期（统一 manual 来源）。循环调用既有单张端点（30 张量级足够），不新增后端接口。全部/隐藏两个 Tab 通用。

### F6 · 内容页导出 JSON 按钮
后端 `GET /api/content/projects/{slug}/export` 已有但 UI 无入口——加「导出」按钮（复制到剪贴板 + 下载 .json）。

### F7 · 登录后跳回原页面
路由守卫带 `redirect` query，登录成功回跳。
