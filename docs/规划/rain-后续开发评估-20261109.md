**踩坑记录（本批新增，均已修复）**：
1. Git Bash 会把环境变量里的 `/rain/` 转换为 Windows 路径 → 本地构建验证必须 `MSYS_NO_PATHCONV=1`
2. Vue 模板表达式不支持 `import.meta`（sourceType 非 module）→ BASE_URL 常量提取到 script
3. patch 顺序 bug 导致 `BASE` 常量定义丢失（运行时 ReferenceError，页面空渲染且无明确报错）→ 本地以 `/rain/` base 复现后定位
4. `read` 是 MySQL 保留字（建表 DDL 失败）→ 列名 `is_read`
5. 浏览器 Origin 逐字匹配：`127.0.0.1` ≠ `localhost`（CORS 白名单两套都要）
6. vite proxy 透传 Origin，前台 dev（5173）调后端时 CORS 白名单必须覆盖 5173
7. github.com 主站被墙但 api.github.com 可达 → 写了 `tools/sync-via-api.py`（Git Data API 重放完整历史，可断点续传）作为推送通道；用户开代理后可直接 `git push`

## 三、下一个大方向：后端公网化（统计/收件箱公网生效的前置）

**现状**：前台埋点与联系表单在公网（GitHub Pages）上无后端接收——埋点静默丢弃、表单降级 mailto（已优雅处理）。**本地跑后端时**（管理台 + 前台 dev）一切可用。

**可选路线（按推荐排序）**：
1. **Cloudflare Worker + D1/KV（推荐）**：免费额度大、国内可达性好；Worker 接埋点/表单写 D1，管理台本地读远端（或 Worker 出只读查询）。改造量：埋点/表单 endpoint 可配置化（已在设计上预留——fetch 相对路径改配置常量即可）
2. **免费容器托管（Render/Fly.io 免费层）**：整个 Spring Boot 上去，管理台也能公网（需 HTTPS + 改密）；免费实例有休眠冷启动
3. **保持本地**：接受统计/收件箱只在本地联调可见（现状），公网访客表单走邮件
   ——**推荐等用户醒后拍板**：涉及账号注册与域名意愿，不适合代做

**代码已为路线 1/2 预留**：前台埋点与表单都是相对路径 fetch，换成配置的公网 endpoint 即可，前台无需重构。
