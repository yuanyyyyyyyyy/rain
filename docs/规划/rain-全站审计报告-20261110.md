### 确认没问题（抽查要点）

- **鉴权**：SecurityConfig 白名单外 `anyRequest().denyAll()`；JWT HS384（48 字节密钥）；登录限流 5 次/15min + BCrypt + 通用错误；Seeder 随机初始口令。
- **注入**：Worker 全部 prepared statements；Spring 无原生 SQL 拼接；slug 创建时 `[a-z0-9-]{2,40}` 校验（防路径穿越写文件）；Jackson 负责全部 JSON 转义；sitemap 只拼已校验 slug。
- **XSS**：前台与管理台 **0 处 v-html / innerHTML / eval**；访客留言、referrer、图注全部走 Vue 插值（自动转义）；`mailto:` 前缀固定无协议注入。
- **CORS**：Spring 白名单仅 localhost dev 端口；Worker `*` 经上一轮评估保留（带 Bearer 才有数据面）。
- **CI**：两 workflow permissions 最小化（`{}` / pages 三项）、无 untrusted input 进 shell、token 走 secrets。
- **仓库卫生**：`*.local`/`*.log`/`.dev.vars`/`.wrangler` 全部正确忽略，工作区敏感文件（`.admin-token.local`、`.admin-password.local`、`application-local.yml`）均未跟踪；`tools/sync-via-api.py` 用 `gh auth token` 无硬编码。
- **发布护栏**：push 前 `merge-base --is-ancestor` 分叉检测 + 拒绝全量重放（11-10 事故修复健在）。
