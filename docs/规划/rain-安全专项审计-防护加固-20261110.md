## 三、审计确认无问题的面（干净项）

- **凭据管理**：`.gitignore` 全覆盖（`*.local`/`*.log`/`.wrangler`/`application-local.yml`/`.dev.vars`）；git 全历史仅 `application-local.yml.example` 被添加过，无真实密钥入库。
- **注入面**：D1 查询全部参数化；Spring 侧 JPA；发布链路 `ProcessBuilder` 全部固定数组命令（git/npm），无用户输入拼接，无命令注入。
- **XSS 面**：前台与管理台 `v-html`/`innerHTML`/`eval`/`new Function` **零命中**；所有动态数据走 Vue 插值/属性绑定；`content/*.json` 站点自控内容与访客输入分离清晰。
- **路径安全**：项目 slug 创建有 `[a-z0-9-]` 白名单 → `content/projects/<slug>.json` 写入无穿越；上传文件名 sanitize 替换 `\/:*?"<>|`；压缩产物服务端重编码为 jpg（恶意载荷不随产物出网），原始副本目录不对外服务。
- **认证**：JWT HS384（jjwt 按密钥长度选算法，弱密钥直接启动失败）；BCrypt；初始口令留空则 SecureRandom 生成 16 位并仅打印一次（无弱默认）；改密校验原密码 + 8-72 位上限；登录失败限流 5 次/15 分（配合 #5 修复后不可绕过）。
- **发布链路**：tmp → 原子替换、写失败不动原文件、发布并发护栏（409）、push 前基线祖先校验（防回退事故复发）、GitHub API 代理为固定 URL 无 SSRF。
- **CI**：`deploy.yml` 仅 main push + dispatch，无 `pull_request_target`，GITHUB_TOKEN 最小权限 + OIDC；`verify-collector.yml` `permissions: {}`，探针 token 走 secret 不落日志明文。
- **Spring 默认安全头**（XFO: DENY / nosniff）未被关闭，隐式生效。
