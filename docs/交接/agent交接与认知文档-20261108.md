## 一、项目认知（这是什么）

### 1.1 一句话

**rain** 是一个个人求职作品集网站（前台纯静态）+ 自托管内容管理后台（Spring Boot 全栈），部署目标为线上可访问、内容可应对面试追问。

### 1.2 项目起源与目的

- 用户（Java 后端求职者）要做一个作品集网站，基于一份设计交接文档和一份 HTML 视觉原型（`yuan_portfolio_klein_blue_v2.html`，原型在项目外，不在仓库内）扩展而成。
- **双重目的**：① 对招聘方展示项目与摄影；② 后台管理系统本身是用户的**第 4 个求职项目**（Java 后端工程实践素材）。因此代码质量、文档、测试都要经得起面试追问。
- 项目代号 **rain**：来自用户名字里的"雨"，与站点蓝调视觉同源。已确定不改名。

### 1.3 站点内容

三个项目详情（case study）+ 摄影页：

## 二、视觉设计系统（不可违背的红线）

视觉基准是 Klein Blue v2，以下规则来自原型提炼，**任何新页面/新组件必须遵守**：

| 原则 | 规则 |
|---|---|
| 一切从白出发 | `#FFFFFF` 唯一背景，层次靠 1px 细线（`#D9DCE0`）+ 留白，不用色块堆砌 |
| 克莱因蓝是标点不是颜料 | `#002FA7` 只用于编号眉标、描边按钮、定位标记、几何线条、hover，占比小 |
| 工业档案感 | 等宽字体编号（DM Mono，字距 ≥0.1em）、`FIG.` / `PLATE.` / `01 /` 图注、虚线基准线、实心/空心方块标记 |
| 几何主视觉是品牌资产 | Hero 的三角形/菱形/交叉线 SVG **1:1 保留**（代码注释标注"视觉资产勿替换"），禁止换成渐变/3D/头像 |
| 硬投影 | hover 用 `4px 4px 0 #CBD7F4`，不用模糊阴影、发光 |
| 质感克制 | 12px 间距极淡点阵肌理（opacity .12），可感知不干扰 |

所有色值/字体/间距变量集中在 **`src/styles/tokens.scss`**（前台）与 **`admin/ui/src/styles/tokens.scss`**（管理台，同源复制）。改主题只动 tokens，不写 magic number。

管理台 UI 同样用这套风格（蓝底白字侧栏 + 白底内容区）。

## 三、技术架构

### 3.1 总览

```
前台（纯静态，部署 Cloudflare Pages 类平台）
  Vue 3.5 + Vite 6 + Vue Router 4 + Sass（无 UI 库、无 axios、无其他运行时依赖）
        ↑ 构建时读取
  src/data/*.js（内容数据，未来由后台写回）

后台（内容管理，可选部署，主要本地跑）
  admin/server  Spring Boot 3.3.5 + Spring Security + JPA + MySQL 8   :8081
  admin/ui      Vue 3 + Vite（hash 路由，fetch 封装）                  :5175
```

### 3.2 发布机制（核心设计决策）

前台**永远是纯静态**：后台编辑内容 → 后端把数据写回 `src/data/*.json`（M4 实现，临时文件原子替换）→ 触发 `npm run build`。数据库只服务后台，不参与前台渲染。

### 3.3 数据驱动架构（改内容不碰组件）

| 数据文件 | 内容 | 消费者 |
|---|---|---|
| `src/data/site.js` | 导航、联系方式（**占位，标 TODO(上线前)**）、首页项目卡片 | SiteHeader/SiteFooter/首页/详情页路由 |
| `src/data/projects/yunshu.js`、`intelnexus.js` | 详情页分节数据 `sections[]` | `ProjectDetailPage.vue` 通用渲染器 |
| `src/data/photos.js` | `photoGroups`（3 组）、`heroPhoto`（当前 p02）、`dims`（30 张实测宽高比表）、`flatPlates` | `PhotographyPage.vue` |

**详情页 sections 类型**（`ProjectDetailPage.vue` 渲染，新增类型需改渲染器）：

| type | 字段 | 用途 |
|---|---|---|
| `arch` | `component: 'yunshu' \| 'intelnexus'` | 架构图 SVG（组件映射在渲染器的 `archMap`） |
| `shots` | `pending: true` 或 `items: [{src, caption}]` | 界面实录网格 + Lightbox；pending 时显示待办虚线框 |
| `impl` | `items: [{title, problem, solution, result}]`，`labels` 可自定义（默认 问题/方案/效果） | 核心实现 / 设计决策 |
| `metrics` | `items: [{label, value, delta?}]` + `note`（测试环境脚注） | 性能数据卡 |
| `pits` | `items: [{title, story}]` | 问题与解决（真实踩坑） |
| `text` | `paragraphs: []` | 概述 / 收获 |

`kicker` 编号格式 `NN / TITLE`；云枢与 IntelNexus 均为 01-07（01 概述 / 02 架构 / 03 界面 / 04 实现 / 05 数据·决策 / 06 问题·质量 / 07 收获）。**新增节必须同步顺延编号**。

**接新项目详情页的步骤**：素材审计 → 新建 `src/data/projects/<slug>.js` → `site.js` projects 数组加卡片 → 渲染器 `details` map 注册（有架构图则画 SVG 组件注册进 `archMap`）。Shimmer 素材回收后照此办理。

### 3.4 摄影页技术要点

- 对齐行排版（justified rows）：贪心装行（累计宽高比 ≥3.3 封行，移动端 2.0），`flex-grow = 宽高比`，行缘精确对齐；`ResizeObserver` 响应式重排

## 七、踩坑记录（不要重踩）

### 7.1 代码层（已修复，面试可讲）

1. **JWT 过滤器双重注册**：`JwtAuthFilter` 标 `@Component` 会被 Servlet 容器自动注册 + `addFilterBefore` 再注册一次，`OncePerRequestFilter` 的 already-filtered 标记导致安全链内那次被跳过 → 全部 401。**修法：无 `@Component`，SecurityConfig 内手动 new。**
2. **`/error` 转发丢认证**：受保护路径 404 后 Spring 转发 `/error`，该转发不带认证上下文，被安全链拦成 401，掩盖真实错误码。**修法：`/error` 加入 permitAll。**

### 7.2 环境层（未修复，只能绕）

3. **本机有 `SERVER_PORT` 环境变量且被占用**：会覆盖 application.yml 的端口 → 启动必须显式 `-Dserver.port=8081`。
4. **bash 环境有 HTTP 代理 `http_proxy=127.0.0.1:7642`**：curl 测试本机服务会走代理导致诡异丢头/502 → **所有 curl 一律加 `--noproxy "*"` 且用 `127.0.0.1`**（排查时曾误判为"Authorization 头丢失"，实际是代理吞的）。
5. **Vite dev server 可能只绑 IPv6（`[::1]`）**：curl `localhost` 不通时先试 `http://[::1]:PORT` 或查 `netstat` 确认监听地址。
6. **残留进程占端口**是常态（本会话多次遇到 5173/5175 被占）→ 起 dev server 前先 `netstat -ano | grep LISTENING` 检查，占了就清理旧进程而不是换端口堆积。
7. **分离式后台进程会被杀**：`( java -jar ... & )` 方式启动的进程随命令结束被工具回收 → 长驻服务必须用后台任务（run_in_background）方式启动。

### 7.3 工具层

8. Git Bash 会把 `robocopy /E` 之类参数误转成路径 → Windows 原生命令（robocopy 等）走 PowerShell 工具执行。
