## 二、本批踩坑（v1 踩坑 #1-#8 仍然有效，在此之上新增）

9. **Git Bash 路径转换污染环境变量**：`DEPLOY_BASE=/rain/` 会被转成 `G:\Tool\...\rain` → 构建产物路径错误。本地验证部署态一律加 `MSYS_NO_PATHCONV=1`
10. **Vue 模板表达式不支持 `import.meta`**（sourceType 非 module，build 失败）→ 需要的值先提取到 script 常量（`const BASE = import.meta.env.BASE_URL`）
11. **批量 replace 的顺序 bug 会静默丢代码**：先做宽匹配再做窄定义替换，定义行会被宽匹配吃掉 → 运行时 ReferenceError 且页面空白无明确报错。教训：**改完必须本地 build + 浏览器复验再 commit/push**（本批因跳过这一步翻过车）
12. **`read` 是 MySQL 保留字**（建表 DDL 静默失败，运行时 SQL 错误）→ 列名用 `is_read`；教训：实体字段名避开 SQL 保留字
13. **CORS Origin 逐字匹配**：`127.0.0.1:5173` ≠ `localhost:5173`（白名单两套都要）；vite proxy 会透传浏览器 Origin——前台 dev 调后端的场景必须把前台端口加进白名单
14. **Windows 命令行 curl 的中文 JSON 会被 GBK 编码搞坏**（400 Bad Request）→ 测试含中文的请求体时用 python 写 UTF-8 临时文件 + `--data-binary @file`
15. **vite preview 端口被占自动 +1**：测前确认实际端口（看启动日志），别对着旧端口上的僵尸服务调试
